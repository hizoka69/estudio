🤖 Crear tarjetas con IA

Sigue estos pasos para convertir cualquier texto o apunte en un mazo importable.

1 Copia el Prompt de IA

Este prompt le indica a cualquier IA (ChatGPT, Gemini, Claude, etc.) que te genere las tarjetas en el formato correcto.

Actúa como un profesor experto y creador de material didáctico. Te voy a proporcionar un documento de estudio (o texto). Tu objetivo es extraer los conceptos clave, definiciones importantes y datos cruciales, y convertirlos en un mazo de tarjetas de estudio (flashcards). Debes devolver el resultado ESTRICTAMENTE en formato JSON válido, sin Markdown, sin saludos, sin explicaciones previas ni posteriores. Solo el código JSON puro. La estructura del JSON debe ser exactamente esta: [ { "pregunta": "¿Escribe aquí la pregunta clara y directa?", "respuesta": "Escribe aquí la respuesta concisa y correcta." } ] Reglas críticas: - Genera al menos 15 tarjetas basadas en el documento. - Las respuestas deben ser claras y directas (1 a 3 oraciones cortas). - Asegúrate de que el JSON sea válido y no tenga errores de formato. Aquí tienes el material de estudio: [PEGA AQUÍ TU TEXTO O APUNTES]
2 Pégalo en una IA y añade tu texto

Ve a ChatGPT, Gemini o Claude. Pega el prompt, reemplaza [PEGA AQUÍ TU TEXTO...] con tus apuntes y envía el mensaje. La IA te devolverá una lista de corchetes [...] con preguntas y respuestas.

3 Guarda la respuesta como archivo .json

Aquí viene la parte clave. Tienes dos opciones:

🅐 En computadora (fácil)

Selecciona toda la respuesta de la IA (desde el primer [ hasta el último ]). Abre el Bloc de notas (Windows) o TextEdit (Mac), pégala ahí. Luego guarda el archivo eligiendo el nombre mimazo.json. ¡Importante! En Windows, pon el nombre entre comillas: "mimazo.json" para que no se guarde como .txt.

🅑 Usando el método directo

Muchas IAs tienen un botón para copiar el código. Copia el resultado, pégalo en jsoneditoronline.org y descarga el archivo desde ahí.

4 Importa el archivo aquí

Vuelve a TCG Study, haz clic en 📥 Importar JSON y selecciona el archivo mimazo.json que guardaste. ¡Listo! Tus cartas aparecerán automáticamente.

💡 Tip: El archivo JSON se ve así por dentro. No te preocupes si no lo entiendes, la IA lo genera automáticamente:
[ { "pregunta": "¿Qué es una base de datos?", "respuesta": "Es un sistema organizado para almacenar datos." }, { "pregunta": "¿Qué significa SQL?", "respuesta": "Structured Query Language, lenguaje de consulta estructurado." } ]
